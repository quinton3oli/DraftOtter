# DraftOtter

A precise, offline CAD tool for designing 3D-printable parts. Everything is in one file: open **`DraftOtter.html`** (from the download package, or built from these sources with `npm run build`) in Chrome, Edge or Firefox (double-click works, no server or internet needed) and export STL.

It is also a web app: **https://localcad-8158c.web.app**. Open it in Chrome or Edge and choose Install (or File → Install DraftOtter) to get it as an app that works offline. The installed app opens `.lcad.json` design files you double-click (Chrome and Edge). When a new version is deployed, it offers to reload. Designs stay on your device: the web app stores them in the browser like the file version does, separately from it.

## Features

- **Shapes:** box (with rounded or chamfered edges), cylinder (chamfer or fillet edges), tube and arc, cone, sphere, dome, torus, wedge, pyramid, polygon prism, star and 3D text. Polygons, stars, text, gears and sketches also take a top/bottom chamfer or fillet.
- **Screw holes:** M2–M8 in five styles (plain clearance, countersunk, counterbore, heat-set insert and nut trap) using typical dimensions, with an adjustable extra clearance.
- **Shell / hollow:** turns any solid into an editable shell with a set wall thickness. The dialog shows a small 3D model of the part: turn it and click the flat faces to leave open, so it works for any shape, not just boxes (outermost faces use the quick Top / Bottom / Front… choices; any other flat face gets an opening inset by the wall). Groups, imports and other complex shapes get exact walls from a true inward offset. An inside corner radius rounds every inside corner and edge of the hollow, and selecting the shell later lets you change the wall thickness and corner radius in Properties.
- **Mechanical parts:** involute spur, helical and herringbone gears; ISO-style metric threads (internal or external, with clearance); hex nut and bolt presets; springs.
- **Advanced library (60+ parametric shapes, searchable):**
  - **Geometric:** capsule, ellipsoid, the five regular solids (tetra/octa/dodeca/icosahedron) plus a geodesic sphere, torus knot, twisted/tapered prism, heart, arrow, cross, slot and Reuleaux triangle.
  - **Containers & pipes:** cup, bowl, funnel and pipe elbow.
  - **Gears & motion:** spur/helical/herringbone gear, ring (internal) gear, gear rack, GT2 timing pulley, cam and spring.
  - **Hardware:** thread, hex nut, hex bolt, washer, hex standoff, D-shaft, spline shaft, knurled knob with a D-shaft socket, and a bearing holder (pillow block).
  - **Structural & joinery:** L-bracket with holes, 2020 T-slot extrusion, dovetail, snap-fit hook, fillet strip, honeycomb panel, grid/pegboard panel and wall hook.
- **Constrained sketches:** draw with Line (D), Arc (B: start, end, then a point it passes through), Circle (C), Rectangle (Q), Slot (W) and Spline (smooth curve through clicked points, with draggable points). Edit with Trim (click a piece to cut it back to where it crosses other geometry), Extend (stretch a line to the next one), Offset (parallel copy of the selected lines, arcs and circles) and, when sketching on a face, Face edges (turns the face outline into sketch geometry, holes as true circles). Tick **Construction** (or press G on a selection) for reference geometry that guides constraints but isn't part of the solid. Every closed loop becomes a solid, and loops or circles inside it become holes, so a plate with bolt holes is one sketch. Constraints: horizontal, vertical, length, radius/diameter, angle, equal, parallel, perpendicular, tangent, coincident, point-on-line/circle, midpoint, symmetric (about a line), concentric, fixed point, X/Y position and corner fillets. A solver keeps them satisfied as you drag points, arc midpoints or circle edges, and the status line shows degrees of freedom, solid/hole count and any open chains. Click any dimension to type a value, math or a variable. Extrude or revolve the result; for a revolve, set where the axis sits (type an X or drag the dashed axis line left or right).
- **Variables & expressions:** define named values (`wall = 2`, `bolt = 3.4`, `width = wall*10 + 5`) and use them in any number field or sketch dimension. Expressions support `+ - * / ^`, parentheses, units (`3/8in`, `2cm`) and functions (`sin`, `cos`, `sqrt`, `min`, `max`, `round`…). Change a variable and every part using it updates. Fields driven by an expression show in purple.
- **Edit a sketch later:** double-click any shape made from a sketch (also inside a group, and pockets) to reopen its sketch and keep working on it; or right-click → Edit sketch, or use the ✎ buttons in the group’s Properties. Changing a pocket’s depth keeps its top on the face it was cut into.
- **Sketch on face (J):** click any face, draw on it (the face outline is shown for reference), then extrude out of it or cut a pocket into it. The result is combined with the part automatically.
- **Hull (Ctrl+H):** wraps one tight convex skin around the selected shapes, like shrink-wrap, so separate parts blend into one smooth piece: two spheres become a capsule, a sphere and a small cylinder become a tapered arm. Hulling a single part fills in its hollows. Holes in the selection are still cut afterwards, and any group can be switched to Hull in Properties.
- **Loft & sweep:** loft blends between a bottom and top profile (circle, rectangle or polygon) with offset, twist and an optional hollow wall, e.g. duct adapters. Sweep runs a profile along a 3D path, either a polyline with rounded corners or a smooth spline, with an optional wall to make tubing.
- **Text fonts:** 53 font families (sans, serif, mono, display, stencil and script, most in regular and bold) bundled for offline use, chosen in a picker that previews each font with your text. Overlapping letter strokes are merged, so text in any font is a clean solid.
- **Resizable panels:** drag the inner edge of the left or right panel to make it wider or narrower (double-click the edge for the default width); the width is remembered.
- **Collapsible panels:** click « / » in a side panel's header (or press Ctrl+[ / Ctrl+]) to fold it into a slim rail and give the 3D view more room; click the rail to bring it back. Print info folds away by clicking its header, and the bar above Objects / Timeline drags up into the Shapes area (⇱ gives the list the whole panel). The layout is remembered.
- **Push / pull (U):** drag any flat face (also on boolean results, and faces with holes) outward to thicken it or inward to cut, with grid snapping and a live preview. Or click a face and type the distance (math and variables work). It stays editable as a "Push/pull" part with a Distance field. Set a **Draft** angle in the push/pull bar to taper flat faces (handy for bosses and pocket walls). Curved faces such as a cylinder's side or a fillet are offset along their surface ("Thicken surface"). A face that runs into rounded edges carries them along (the rounding moves with the face instead of being left behind), and a face bounded by curved walls is moved cleanly. Each push/pull remembers the face it was made on and finds it again when something before it changes: make the box taller and the pull starts from the new top; make it wider and it covers the whole new face. Features are applied in the order they were made.
- **Fillet & chamfer any edge (G):** works on finished parts, including after booleans. The part's real edges are outlined; click to select, click a face to select every edge around it (or pick All / Outer edges), set a radius or chamfer distance, and Apply. Tick **Variable** to change the size along each edge, from a start size (green dot; Flip swaps the ends) to an end size — closed loops go out to the end size halfway round and back. Outside edges are rounded off and inside corners filled in, along straight or curved edges such as a hole's rim. It stays editable (select "Fillet" in Objects to change the size), and there's a "Round whole part" option. Where three filleted edges meet at a corner, the corner is blended with a smooth spherical patch.
- **Offset / thicken:** grow or shrink any object or group by a distance, with rounded results. It stays editable as a group, which makes clearance cut-outs easy (offset 0.2 mm, make it a hole).
- **Booleans:** mark any shape as a hole, then group. Booleans run on the Manifold kernel, so exported STLs are always watertight. Groups stay editable: expand a group (or double-click it) to change any part.
- **Precision:** every number field accepts math and units (`25.4*2`, `3/8in`, `2cm`). You can also step values with ↑/↓ or drag a field's label to scrub.
- **Direct editing:** click any size label in the view to type an exact size. Scale handles move one side at a time (or two sides from a corner) and snap to the grid. Rotate rings snap to your rotate step (15° by default) while you drag on the ring; move the pointer outside the ring (or hold Shift) for 1° steps, shown by a fine protractor scale. The angle and step size show next to the cursor. Arrow keys nudge relative to your view (snapped to the grid axes) and Ctrl+↑/↓ nudges along Z, and zooming centers on whatever is under the cursor, so you can get very close.
- **Workplane (K):** click any face to build on it. New shapes stand on that face, and dragging moves things across it. Click the bed to go back.
- **Space evenly (Shift+L):** select two or more objects and space them along X, Y or Z with equal gaps or equal center-to-center distances. Either fit them between the first and last object (those two stay put) or type an exact gap or pitch (math and variables work), starting from the first object. Also in the toolbar, the right-click menu and Properties.
- **Arrange on a circle (Arrange menu):** spaces the selected objects evenly around a circle around Z, X or Y — full circle or any arc, from a start angle, optionally turning each object with the circle like spokes — with a live preview and the circle drawn in the view. Running it again on objects that are already on a circle picks up that circle, so you can just change the radius (type it or drag the slider). Works on holes inside a part too, for bolt circles.
- **Smart snapping:** new shapes, dragged objects, shapes dropped onto a face and Place on face (P) all put the object's center on the snap grid (on a face, the grid lies in that face's plane). Dragged objects also line up their edges and centers with nearby objects, shown by pink guide lines. Hold Alt to turn snapping off.
- **Picking hidden objects:** clicking the same spot again selects the next object behind. Alt+click (or right-click → "Select object here") lists everything under the cursor, including parts inside groups.
- **My parts:** save any selection as a reusable part. It appears in the Shapes panel in every design on this browser.
- **Align (L):** dots appear around the selection, three per axis. Hover one to preview the result and click it to apply. Click an object to make it the anchor that everything else lines up to; a single object aligns to the bed. You can also space objects evenly.
- **Tools:** move gizmo with snapping, drag on the workplane, mirror, linear / circular / grid pattern or a pattern along a path (any sketch's line, arc, spline or circle, or a path drawn on the spot; copies can turn to follow it), duplicate (repeat it to repeat the last move), drop to bed, place on face, measure (click two faces for the perpendicular gap between them and their sideways offset, drawn as two dimension lines — e.g. a cylinder’s top face to the bed gives its height; faces at an angle give the angle; two points give the distance with its X / Y / Z legs; in a section view the cut surface itself can be measured — its corners and edges snap and holes cut through show their diameter; snaps to corners and circle centers; click a circular edge, arc, hole, cylinder or sphere to get its diameter, radius and center), round dimensions (Tools → Round dimensions: snap sizes, positions, scaled sizes and rotations of the selection or the whole design to 1 / 0.1 / 0.01 mm or any step, with a preview; values set by expressions are left alone). Precision is kept tidy automatically: float noise in positions, sizes and outlines (46.9999 for 47) snaps to the micron, push/pull features (outline, depth, placement) are kept on whole microns, and sizes made by scaling come out exact, so parts meant to be flush join without hair-line steps, section view (pick Side X / Front Y / Top Z or On a face; slide the cut with the Position slider, − / + or a typed value; tilt it with the two angle fields or the gizmo's rings, which turn the plane exactly as far as you sweep around them — 15° steps on the ring, 1° out past it or with Shift, Alt free; Straighten undoes the tilt; Look at cut turns the view to face the cut; Other half and Show plane toggles), overhang highlighting and a view cube with orthographic mode.
- **STEP export:** File → Export STEP (or pick STEP in Export) writes solids that open in Fusion, SolidWorks, Onshape, FreeCAD and others. Flat areas become real faces (a box imports as 6 faces), and cylinders — holes, pins, tubes, slot ends, round edges — become true cylindrical faces with circular edges, so you can measure and fillet them there (a cylinder imports as 3 faces). Other curved surfaces come through as fine flat facets. Checked by reading files back with OpenCascade.
- **STEP / IGES import:** File → Import STEP / IGES (or drag the file in) reads parts and whole assemblies from other CAD tools through an embedded OpenCascade reader (started on first use): every body becomes a part with its name, color and position, in millimeters.
- **Hole Wizard (Modify):** standard holes — ISO metric M2–M12 and ANSI #4–½" — as clearance (close / normal / loose), tapped (tap drill, or modeled threads), counterbore, countersink (90° / 82°), heat-set insert or nut trap, blind or through. Click points on any flat face (snapped to the grid in that face) to drill them; each hole stays editable and shows its callout. Pattern and Mirror copy work on holes and other features inside a part.
- **3MF import:** File → Import 3MF (or drag it in) opens models from Printables, MakerWorld and Thingiverse and saved Bambu Studio / OrcaSlicer / PrusaSlicer projects: every object becomes a part with its name and color, laid out as on the plate, in the right units.
- **Photoreal render (Views menu, File):** path-traced pictures of the design on your graphics card — matte or glossy plastic, silk, metal or clear resin in each part's color, a light, dark, white or transparent studio backdrop with soft shadows and reflections — refined until the chosen quality, saved as PNG at view size, HD, square or 4K.
- **3MF export:** one file with every part as its own named, colored object in millimeters, so Bambu Studio, PrusaSlicer, OrcaSlicer and Cura can assign a filament per part.
- **Images → sketches:** File → Import image, or More (wrench icon) → Import image (or drag a PNG / JPG / WebP onto the view) traces a logo, icon, silhouette or drawing into an editable sketch: live preview, automatic threshold, Invert for light-on-dark, smoothing, detail level, speck filter, size in mm and extrude height. Shapes inside shapes become holes. Works offline.
- **Images → relief / lithophane:** File (or More) → Image → relief / lithophane turns a picture’s brightness into thickness: a lithophane (darker is thicker, for light to shine through), or a relief where the light or the dark parts stand up. Set the width, thinnest/thickest, an optional frame, detail and smoothing; the result is a watertight mesh part.
- **OBJ / glTF / GLB import:** File → Import OBJ / glTF / GLB brings in meshes from other apps and from AI image-to-3D tools (Draco and meshopt compressed GLBs included): Y-up models are stood up on Z, and you set the longest side in mm; one part per mesh, or merged.
- **DXF / SVG:** import a DXF or SVG as an editable sketch part (closed outlines become solids, inner outlines holes; DXF arcs stay true arcs), or add one to a sketch with the sketch editor's Import button. Export any sketch as DXF or SVG, or a slice through a part (File → Export section) for laser cutting and CNC.
- **Check for printing (toolbar ✓):** one panel flags thin walls, narrow gaps that may fuse shut, pieces floating in the air, parts below the bed, overlapping parts, overhangs and build-volume fit, and highlights each problem in the view. Minimum wall and gap are adjustable.
- **Center of mass:** Print info shows surface area and the center of mass (Show draws it with its footprint), and warns when a part will tip over on the bed.
- **Split part (Tools):** cut a part with a plane into two editable halves, optionally with alignment-pin holes (and the pins as separate parts), and lay both halves cut-face-down ready to print. The cutting plane and pin positions preview live.
- **Fits & tolerances:** give any hole (including groups, meshes and sketches) a fit — press, snug, sliding, loose or a custom clearance — and it prints that much larger. Pick which of the object’s own directions it grows in (X, Y, Z): round and box holes default to X+Y, so through-holes don’t get deeper; other shapes grow every way. Select several holes to set their fit all at once (a progress bar shows while custom-shaped holes are rebuilt). Growing is quick: convex pieces and straight extrusions (text, sketches, polygons) take a fast exact path, a group is grown one solid at a time, and slow results are kept in the browser so reopening a design doesn’t grow them again. Settings → Hole compensation adds your printer's own correction to every fitted hole; Tools → Fit test print makes a calibration plate and peg to find it.
- **Wrap / emboss (Tools):** wrap text (or a sketch) around a cylinder, raised or engraved, at any angle and height. It stays editable and fuses watertight with the cylinder.
- **Assemblies (Assemble menu):** mated parts stay attached (move the base and they follow; move the part and it re-attaches where you put it; Detach in the Joints & attachments panel). Exploded view spreads the parts for a look inside (display only). Bill of materials counts identical parts and lists size, volume and mass, with CSV download.
- **Assemblies, continued:** Mate parts — click a face, rim or shaft on the part to move, then the face or hole it attaches to — with Flip, 90° turns and an offset. Turn a mate into a hinge or slider joint, move it with a slider in the Joints panel, and check collisions over its whole range. Interference check lists every overlap between parts.
- **Configurations:** in Variables, save sets of values (Small / Large, M3 / M4…) and switch between them; Export can write every configuration as its own file in one zip.
- **Templates:** a group can have its own Parameters (Properties), used by everything inside it, so each copy can have different values. Make template turns the design variables a group uses into parameters and saves it to My parts.
- **Feature timeline:** the Timeline tab (next to Objects) lists every step in the order it was made. Untick a step to suppress it, roll the design back to any step (new work is inserted there), then roll to the end.
- **History & branches (the ⎇ chip next to the design name, or File → History & branches):** commit the design with a message whenever you like; every Save also commits when something changed. The chip shows the current branch, and a dot means there are changes since the last commit. The History window shows the commits as a graph with thumbnails, branch names and tags. From there you can:
  - **Compare** any commit with the current design (shown as a ghost, with a list of what changed), or **Restore** it.
  - **Branches:** start one to try an idea without touching your main design. Switching branches asks first if you have uncommitted changes.
  - **Merge** a branch back in. Changes to different parts or different settings combine automatically. When both branches changed the same thing (for example the same part's height), a panel lists each clash with both values. Click one to see the other branch's version as a ghost, then choose Mine or Theirs; the view updates as you choose. Finish or Cancel the merge.
  - **Apply changes from a commit** (cherry-pick) brings in just the parts you tick.
  - **Tags** mark commits such as "printed v2".
- **History of one part (right-click a part):** the commits that changed it and what changed. "Use this version" puts just that part back.
- **History storage:** parts are stored once and shared between commits, so a long history stays small. Older files' versions become commits on main when opened. Undo steps survive reloading the page.
- **2D drawings (Inspect):** also a section view A–A (cut through the middle, cut faces hatched, cut line marked on the top view), detail views (click a spot to magnify it 2×) and click-to-dimension (two clicks on a view; corners and circle centers snap; click a dimension to remove it). These are saved with the design.
- **Stress check (Inspect):** a basic finite-element check — click the faces that are held still and the faces that are pushed, set the force and material (PLA, PETG, ABS, ASA, nylon, PC, aluminum, steel), and see a stress color map, peak stress, deflection, a safety factor and the exaggerated deformed shape. It solves on a brick model of the part in a background worker, checked against beam theory to within about 1–2%; results assume solid, equally strong material, so aim for a safety factor of 2 or more on printed parts.
- **2D drawings, basics:** front, top and right views (third-angle) plus an isometric, with hidden lines, overall dimensions, hole diameters with center marks and a title block, on Letter, Tabloid, A4 or A3. Print / save as PDF, or download SVG or DXF.
- **Display settings:** Settings → Display sets the 3D view’s background color (pick any color or a preset) and can hide the print bed altogether.
- **Surface texture (Modify menu):** gives a part a knurl, ribs, waves, bumps (or dimples, with negative depth), hexagon ridges or an organic noise surface. Set the size, depth and angle, choose which faces it covers (all, sides, top, bottom), and wrap it seamlessly around round parts. It stays editable: change the part inside and the texture follows.
- **Deform (Modify menu):** bend, twist or taper a part along X, Y or Z, or reshape it freely with a 2×2×2 to 4×4×4 lattice. Choose Edit lattice points, then drag the points in the view; hold Shift to move along one axis. The values can be variables. Textures and deforms build in the background workers.
- **Sculpt (Modify menu, right-click, or Properties → Sculpt…):** shape a part's surface with brushes, like Blender's Sculpt Mode.
  - **Starting:** choose a detail level (the triangle count is shown). The part becomes an evenly subdivided mesh with exactly its shape. The brush starts at a size that suits the part, and the view zooms in if the part is tiny on screen.
  - **Brushes:** Draw, Clay, Inflate, Smooth, Flatten, Pinch, Crease and Grab, with radius, strength and falloff. A ring follows the surface under the pointer. Left-drag sculpts; right-drag still orbits. Strokes are processed once per screen frame, and library pictures are only drawn while you are idle, so brushing stays smooth.
  - **Keys:** 1–8 pick brushes. Ctrl inverts (dig instead of raise). Shift smooths. F sets the radius and Shift+F the strength, by pointer distance, like Blender; [ and ] resize the brush. X, Y and Z toggle mirror symmetry (off to start; when on, a purple ring shows each mirrored spot). Ctrl+Z and Ctrl+Shift+Z undo and redo strokes. Enter finishes.
  - **Refine** adds detail (about 2.5× the triangles) and can be undone.
  - **Done** makes the result a solid mesh part you can cut, join and export. **Cancel** discards the session.
  - **Keeping the original:** the part as it was before sculpting is kept, so Properties offers **Back to the original part**, and **Keep sculpting** goes straight back in.
  - **Storage:** sculpted meshes are stored indexed, about half the size of a triangle list. Designs too big for the browser's localStorage autosave to IndexedDB instead.
- **Printing:** printer bed presets, build-volume check, and volume, weight and filament estimates. STL export can cover the whole design, the selection, or each object as its own file, with an option to merge everything into one solid.
- **Background geometry:** joins, offsets and fit growth run in background workers (up to four at once), so slow rebuilds don’t freeze the page and independent parts build in parallel — on loading, when applying fits, and when an edit touches a part that was slow to build before (a progress bar appears if it takes a moment). Until a rebuild finishes, the view keeps showing the previous shape.
- **Tabs:** open several designs at once.
  - **Opening:** **+** (or File → New design) starts one. Open and dragged-in design files get a new tab, unless the current tab is empty and untouched.
  - **Each tab is its own design:** with its own undo, history and branches, file, selection and camera view.
  - **The tab strip:** a dot marks unsaved changes, and **×** or a middle-click closes a tab (it asks first if there are unsaved changes). Drag tabs to reorder them.
  - **Copy and paste between tabs:** imported and sculpted meshes come along.
  - **After a reload:** open tabs come back, each autosaved on its own. Background tabs load when you click them.
- **Files:** Save (Ctrl+S) writes back to the same file once it has one, and Save as (Ctrl+Shift+S) picks a new name and location. Chrome and Edge use the system file dialog; other browsers download a `.lcad.json` file. A badge shows saved or unsaved changes. Designs also autosave in your browser. You can open designs and import STL (drag and drop works). While a design is being built — at startup, when opening a file, switching branches or restoring a commit — a loading screen shows which shape is being built and how far along it is (quick opens skip it).

**Mouse:** right-drag rotates the view, middle-drag pans, the wheel zooms to the cursor. Left-click selects, left-drag moves objects (or box-selects on empty space), and right-click opens the object menu.

Press **?** in the app to see all shortcuts.

## Working with Claude

Claude, with your own Claude subscription, can design with you. It reads the open design, adds shapes and custom sketches (extruded or revolved, with arcs and holes), cuts holes, uses design variables, checks its work with screenshots and print stats, and exports STL, 3MF or STEP files. Every change shows up live in DraftOtter and can be undone with Ctrl+Z.

1. In DraftOtter, open **More (wrench) → Connect Claude** and tick **Allow Claude to connect**. A badge in the status bar shows the connection.
2. Set up Claude once:
   - **Claude Desktop:** install `claude/DraftOtter.mcpb` (from the release zip, or `npm run dist`) by double-clicking it or dragging it onto Settings → Extensions. Nothing else is needed.
   - **Claude Code:** run `claude mcp add draftotter -- node "<path>/claude/draftotter-mcp.mjs"` (needs Node.js 18+). The Connect Claude dialog shows the exact command for your copy.
3. Ask, for example: “add a 60 × 40 × 3 mm plate with M3 countersunk holes 5 mm in from each corner”.

How it works: `claude/draftotter-mcp.mjs` is a small MCP server without dependencies. Claude starts it, and the DraftOtter page connects to it over a WebSocket on 127.0.0.1 (port 47821, which you can change). Only pages opened from a file (or served by the helper) are accepted, only one DraftOtter window connects at a time, and nothing connects while the box is unticked. Exported files go to your Downloads folder unless Claude is given a path. In Claude Desktop you can change the folder in the extension's settings; for Claude Code, set `DRAFTOTTER_EXPORT_DIR`. The tools are `get_design`, `list_shape_types`, `add_shape`, `sketch`, `update_object`, `move`, `combine`, `ungroup`, `duplicate`, `delete_objects`, `set_variables`, `get_stats`, `screenshot`, `select`, `undo` and `export`.

## Development

```
npm install
npm run build      # bundles src/ into DraftOtter.html
npm run watch      # rebuild on change
npm test           # geometry/CSG checks + headless browser tests (needs Chrome or Edge)
node test/startup.bench.mjs   # startup time (warm) of the web app and the single file
node test/edit.bench.mjs      # everyday editing on a big design (edits, selection, autosave, frames, tabs, dragging)
node test/fuzz.test.mjs [seed] [steps]   # random-use stress test (also part of npm test)
npm run web        # the installable web app (PWA) into web/: index.html, manifest, icons, service worker, Claude downloads
npm run deploy     # build web/ and publish it to Firebase Hosting (project localcad-8158c; needs `firebase login`)
npm run dist       # end-user zip: DraftOtter.html, readme, licenses, and the Claude extension (DraftOtter.mcpb)
```

The web app's extra files are in `pwa/` (manifest, service worker, icons) and `src/pwa.js` (install, updates, opening files); `firebase.json` sets the hosting headers.

Startup: library thumbnails are kept in the browser per build and drawn in idle time after the app is ready; the 3D view compiles its shaders in the background before the first frame, and the release build skips the per-shader error check (turn it on with `localStorage['draftotter-debug-shaders'] = 1`).

Source is in `src/`: `shapes.js` (parametric geometry), `engine.js` (caching and CSG), `viewport.js` (3D view and interaction), `app.js` (UI and commands), `sketch.js` (2D profile editor) and `model.js` (document and undo). Feature modules: `threemf.js` / `zip.js` (3MF), `vector.js` / `vectorUI.js` (DXF & SVG), `printcheck.js`, `analysis.js` (mass properties), `split.js`, `fits.js` / `fitcache.js`, `csgcore.js` / `csgworker.js` / `workers.js` (geometry kernel and background workers), `wrap.js`, `assembly.js`, `params.js` (configurations & templates), `timeline.js`, `history.js` (commit graph and three-way merge), `historyui.js` (History & branches), `versions.js` (visual compare), `sculpt.js` (sculpting brushes and mesh) and `sculptui.js` (Sculpt mode), `tabs.js` (design tabs), `drawing.js`, `step.js` and `claudelink.js` (the page side of the Claude connection; the MCP server is `claude/draftotter-mcp.mjs`, and `claude/manifest.json` describes the Claude Desktop extension).
